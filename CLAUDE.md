# KudoLit — Kudos Board Generator

## Overview
A Streamlit-based kudos board application backed by PocketBase (hosted on Pockethost). General-purpose tool for creating shareable kudos/appreciation pages for any person or occasion.

## Tech Stack
- **Frontend**: Streamlit (latest)
- **Backend/DB**: PocketBase via Pockethost (instance exists, schemas need creation)
- **Python**: Latest stable
- **Libraries**: Pick what fits best (e.g., `requests` or PocketBase Python SDK for API calls, `Pillow` for image handling if needed)

## Access Model
Each kudo page has **three access codes** (~10 alphanumeric characters each), generated together when a page is created. All three are different.

- **Admin code**: Full control — create/delete kudo pages, delete messages, see all three codes
- **User code**: Can add kudo messages (text + media) to the page
- **Viewer code**: Read-only view of the kudo page

Entry flow: User lands on the app and enters a code. The app determines the role (admin/user/viewer) and the associated kudo page by looking up the code in PocketBase, then renders the appropriate view.

Codes should also work as URL query parameters (e.g., `?code=abc123`) for easy sharing.

## Views

### Admin View
- Overview/dashboard of **all** kudo pages the admin has created
- For each page: shows all three codes (admin, user, viewer)
- Can create new kudo pages (sets heading, optional theme/background)
- Can delete kudo pages
- Can delete individual messages on any page

### User View
- Sees the kudo page with its heading and existing messages
- Can add new messages:
  - Rich text formatting (bold, italic, etc.)
  - Optional image/gif: URL paste **or** file upload (PocketBase supports file storage)
  - Character limit: 5000 characters
  - No limit on number of messages per user

### Viewer View
- Read-only view of the kudo page
- Sees heading, theme/background, and all messages with their media

## Kudo Page Properties
- **Heading**: Customizable text
- **Theme/Background**: Customizable (color, optional background image or preset themes)
- **Persistence**: Pages exist indefinitely once created

## Visual Style
- Minimal and elegant
- Card-based layout for messages
- Clean typography, generous whitespace

## PocketBase Schema

### Collection: `kudo_pages`
| Field           | Type     | Notes                                      |
|-----------------|----------|--------------------------------------------|
| `id`            | string   | Auto-generated by PocketBase               |
| `heading`       | text     | Page title / occasion                      |
| `theme`         | json     | Stores background color, theme preset, etc.|
| `admin_code`    | text     | ~10 char alphanumeric, unique, indexed     |
| `user_code`     | text     | ~10 char alphanumeric, unique, indexed     |
| `viewer_code`   | text     | ~10 char alphanumeric, unique, indexed     |
| `created`       | datetime | Auto                                       |

### Collection: `kudo_messages`
| Field           | Type     | Notes                                      |
|-----------------|----------|--------------------------------------------|
| `id`            | string   | Auto-generated by PocketBase               |
| `page`          | relation | Relation to `kudo_pages`                   |
| `author_name`   | text     | Display name of message author             |
| `content`       | text     | Rich text / markdown, max 5000 chars       |
| `image_url`     | url      | Optional external image/gif URL            |
| `image_file`    | file     | Optional uploaded image/gif                |
| `created`       | datetime | Auto                                       |
